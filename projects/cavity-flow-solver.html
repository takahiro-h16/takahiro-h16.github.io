Overview

The lid-driven cavity is the standard first benchmark for an incompressible Navier–Stokes solver: a square box of fluid, closed on three sides, with the top wall sliding at a constant velocity. It has no analytic solution, but the reference data of Ghia et al. (1982) makes it easy to tell whether your code is right.

正方形キャビティの上面だけを一定速度で動かす「リッドドリブンキャビティ」は、 非圧縮 Navier–Stokes ソルバーの最初のベンチマークとして定番の問題です。 解析解はありませんが、Ghia et al. (1982) の参照データと比べることで、 実装が正しいかどうかをはっきり判定できます。

Governing equations

The solver works with the incompressible Navier–Stokes equations in primitive variables,

\[ \frac{\partial \mathbf{u}}{\partial t} + (\mathbf{u} \cdot \nabla)\mathbf{u} = -\frac{1}{\rho}\nabla p + \nu \nabla^2 \mathbf{u}, \qquad \nabla \cdot \mathbf{u} = 0 , \]

where \(\mathbf{u} = (u, v)\) is the velocity field, \(p\) the pressure, \(\rho\) the density and \(\nu\) the kinematic viscosity. Non-dimensionalising with the lid velocity \(U\) and the cavity width \(L\) leaves a single parameter, the Reynolds number

\[ \mathrm{Re} = \frac{U L}{\nu}. \]

Because the velocity and pressure are coupled only through the incompressibility constraint, each time step uses a projection (fractional-step) method: advance the momentum equation to an intermediate velocity \(\mathbf{u}^{*}\), then correct it with the solution of a pressure Poisson equation,

\[ \nabla^2 p^{\,n+1} = \frac{\rho}{\Delta t}\, \nabla \cdot \mathbf{u}^{*}, \qquad \mathbf{u}^{\,n+1} = \mathbf{u}^{*} - \frac{\Delta t}{\rho}\nabla p^{\,n+1}. \]

速度と圧力は非圧縮条件を通じてのみ結合しているため、各時間ステップでは射影法（分数ステップ法）を使います。 まず運動方程式を進めて中間速度 \(\mathbf{u}^{*}\) を得て、次に圧力 Poisson 方程式を解いた結果で補正し、 発散ゼロの速度場に射影します。

Implementation sketch

The pressure Poisson solve dominates the runtime, so it is the part worth showing first. The code below is the straightforward SOR version used to get the solver correct before optimising it.

import numpy as np


def pressure_poisson(p, b, dx, dy, omega=1.7, tol=1e-6, max_iter=10_000):
    """Solve the pressure Poisson equation by SOR with Neumann walls.

    Parameters
    ----------
    p : (ny, nx) ndarray
        Pressure field; used as the initial guess and overwritten in place.
    b : (ny, nx) ndarray
        Right-hand side, rho/dt * div(u*).
    """
    dx2, dy2 = dx**2, dy**2
    denom = 2.0 * (dx2 + dy2)

    for it in range(max_iter):
        p_old = p.copy()

        p[1:-1, 1:-1] = (1.0 - omega) * p[1:-1, 1:-1] + omega * (
            dy2 * (p[1:-1, 2:] + p[1:-1, :-2])
            + dx2 * (p[2:, 1:-1] + p[:-2, 1:-1])
            - b[1:-1, 1:-1] * dx2 * dy2
        ) / denom

        # Neumann (dp/dn = 0) on all four walls; pressure fixed at one corner
        # to remove the constant null space.
        p[:, 0] = p[:, 1]
        p[:, -1] = p[:, -2]
        p[0, :] = p[1, :]
        p[-1, :] = p[-2, :]
        p[0, 0] = 0.0

        if np.linalg.norm(p - p_old) < tol:
            return p, it

    return p, max_iter
